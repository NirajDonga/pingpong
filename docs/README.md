# PingPong Context

This folder stores project context.

Each file contains one type of information only.

Read in this order:

```txt
1. overview.md
2. architecture.md
3. services.md
4. tech-stack.md
5. requirements.md
6. build-phases.md
7. file-structure.md
8. coding-style.md
9. later-scope.md
```

Rule:

```txt
Do not turn one context file into a dump of everything.
If the information is a different type, put it in a different file.
```
